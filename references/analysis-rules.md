# 분석 기준

## 범위와 결측

기본 주 분석은 모든 문항 점수가 확인된 학생(완전 사례)을 대상으로 한다. 학생 수, 분석 수, 전 문항 결측 수, 일부 문항 결측 수, 명시적 제외 수를 표시한다. 실제 숫자 0과 전 문항 0점은 포함한다. 전 문항 빈칸에 SUM 결과만 0인 행은 제외하되 결시라고 단정하지 않는다. 일부 결측을 0으로 대체하지 않는다. 결측이 많으면 제외에 따른 편향과 유효 표본 감소를 짧게 설명하고, 필요하면 관측값 기준 문항별 분석을 별도로 계산하여 각 분모를 명시한다. 사용자가 다른 처리 규칙을 정하면 이를 우선하고 스크립트도 그에 맞춰 수정한다.

대시·결시·미응시 등은 원본 의미를 확인하고 missing_tokens 또는 제외 행으로 명시한다. 기본 숫자 파서는 빈 문자열/null만 결측으로 취급하고 그 외 비숫자는 중단한다. 불리언, NaN, 무한대, 음수는 기본적으로 오류다. 실제 감점 시험이면 원인 확인 후 별도 분석 규칙을 적용한다.

선택한 원본 행 번호, 제외 이유, 검증 결과는 작업용 JSON에 기록한다. 학생 ID는 입력 안에서 중복 확인에만 사용하며 결과 JSON/보고서에는 저장하지 않는다. 반 이름은 명시된 열 또는 확인된 시트별 class_label에서만 얻는다. 일부 반 정보가 없으면 미분류로 집계하고, 반별 n을 표시한다. 집단별 응시 시험이나 배점이 다르면 합치기 전에 비교 가능성을 확인한다.

## 수치와 검증

- 총점: 문항 원점수의 합. 원본 총점이 있으면 모든 완전 사례에서 대조한다. 불일치는 가산점·가중치·오류 등을 해결하기 전 중단한다. 공식 가중치 시험은 스크립트를 조정하고 공식을 명시한다.
- 평균·표준편차: 표본 SD(ddof=1), n<2이면 미산출. 사분위수는 선형 보간. 문항 평균 합=총점 평균을 검증하며 Python 표준 라이브러리로 평균과 SD를 독립 대조한다.
- 원본 평균 수식: 학생 첫/끝 행 누락, 요약행 포함, 빈칸과 SUM=0 처리, 낡은 캐시 등을 확인한다. 캐시값만 읽는 라이브러리는 수식을 재계산하지 않는다. XLSX 수식과 data_only 값을 함께 검사하고 필요하면 작업용 복사본에서 계산한다. XLS 수식 확인이 필요하면 원본을 보존하여 변환본을 검사한다.
- 배점: 출처가 확인된 양수만 사용한다. 각 점수가 배점을 넘는지, 모든 배점의 합과 공식 총점 만점이 같은지 검증한다. 관측 최댓값은 점수 범위일 뿐 만점이 아니다.
- 변동계수: 표본 SD/평균×100. 평균 0 또는 SD 미산출이면 미산출. 평균이 작으면 커질 수 있어 변별력으로 해석하지 않는다.

## 난이도와 변별력

공식 문항 배점이 있으면 난이도 지표는 평균/배점×100인 **평균 득점률**(높을수록 쉬운 경향)이다. 부분점수 시험에서는 정답률과 다르다. 공식 배점이 모두 없는/일부만 있는 경우 전체 비교 그래프는 **점수 획득률**=0점 초과 학생 수/분석 학생 수×100을 쓴다. 평균 득점률과 획득률의 단위를 한 그래프에 섞지 않는다. 쉽다/어렵다의 절대 구간은 시험 목적에 따라 결정하며 자동 합격선이나 보편적 품질 등급을 만들지 않는다.

변별력은 전체 분석 집단의 총점 상·하위 27%(ceil) 문항 평균 차이로 제시한다. 경계 동점자는 모두 포함하고 실제 상·하위 n을 밝힌다. 두 집단이 겹치면 변별력은 미산출한다. n<4도 미산출한다. 배점이 전부 확인되면 차이/배점으로 정규화하고, 아니면 원점수 차이를 사용하여 큰 배점의 영향이 있음을 표시한다. 배점으로 나눈 값은 비율(−1~1), 득점률은 %로 구별한다. 보조 지표인 수정 문항총점 상관은 문항 점수와 나머지 문항 합의 Pearson 상관이며 둘 중 하나가 일정하면 미산출한다. 기본 간결 보고서에는 상관 표를 추가하지 않는다.

반이 있으면 반별 분포와 평균·SD를 비교하고 히트맵을 추가한다. 단순 평균 차이로 유의한 차이가 있다/없다고 쓰지 않는다. 검정이 필요하면 시험 설계와 독립성, 집단 수, 표본을 확인해 적절한 검정을 별도로 수행하고 효과 크기와 불확실성을 함께 설명한다. 인과적 수업 효과로 단정하지 않는다.

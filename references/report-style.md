# 간결한 한국어 보고서

이번에 합의한 형식은 독립된 표지 없이 제목부터 시작하는 A4 세로 보고서다. 기본 5쪽 정도, 반별 히트맵을 추가하면 6쪽 정도다. 반·문항이 많으면 가독성을 위해 늘리고 4~5쪽에 억지로 압축하지 않는다. 사용자가 새 참고 문서를 주면 그 구성을 먼저 확인한다.

- 여백 약 2.2~2.5cm, 본문 한글 고딕 11pt, 제목 24pt, 큰 제목 16pt, 작은 제목 12pt, 그림 설명 9pt.
- 검정 제목, 흰 배경, 파랑·주황·초록의 일관된 차트 색상. 긴 표·방법론 부록은 기본적으로 생략한다.
- ‘소제목 → 핵심 수치 2~4개 → 짧은 해석 → 그림’ 순서. 과도한 약어와 수식 대신 처리 기준을 관련 위치에 한 번 명시한다.
- 평균·SD·총점은 소수 둘째 자리, 비율·CV는 첫째 자리. 본문 종결은 ‘~했습니다/~있습니다’. 반 이름·문항 번호는 실제 자료를 따른다.

## 구성

1. 분석 개요와 전체·반별 분포: 모집단/분석/제외 수, 문항 수와 만점 확인 여부, 반 유무, 평균·SD·중앙값·범위. 결측·0점 기준과 검증 결과를 짧게 표시한다.
2. 문항별 변동성: 평균·SD·CV·관측 범위. 높고 낮은 CV의 대표 문항만 언급한다.
3. 난이도: 배점 확인 시 평균 득점률, 아니면 점수 획득률. 대표 문항을 수치와 함께 해석한다. 부분점수를 정답이나 만점으로 해석하지 않는다.
4. 변별력: 상·하위 실제 인원과 평균 차이(공식 배점이 전부 있으면 정규화). 0·음수·미산출을 구별한다. 히트맵은 반 정보가 있을 때 문항 분석에 추가한다.
5. 종합 평가와 결론: 분포, 문항 특성, 개선 제안. 결론은 전체 결과 / 실제 주요 문항과 개선 방향 / 향후 활용의 3문단으로 쓴다. 이전 시험의 결과를 복사하지 않는다.

## 그래프

- 그림 1: 총점 KDE·히스토그램·바이올린·상자그림. 반이 있으면 반별로 비교, 공통 점수축·구간을 사용한다. n<3 또는 분산0이면 KDE/바이올린 대신 관측점과 미산출 설명을 표시한다.
- 그림 2: 문항 평균·SD·CV·관측 범위의 4패널.
- 그림 3: 반별 문항 평균·SD의 2패널. 반이 없으면 전체 집단을 표시한다.
- 그림 4: 난이도 지표·변별력의 2패널. 미산출값은 빈칸/주석으로 구분한다.
- **반 정보가 있으면 추가 그림: 반×문항 히트맵**. 배점이 전부 확인되면 평균 득점률(0~100%) 공통 척도, 아니면 원점수 평균 공통 척도. 값이 없는 반은 회색/미산출로 구별하고 n=0을 표시한다. 숫자 주석은 공간이 충분할 때만 표시한다. 반마다 색상 범위를 바꾸지 않는다.
- 같은 글꼴·축 단위·범례를 사용한다. 문항이 많으면 구간별로 그림을 나누고 반이 많으면 페이지를 나눈다. 과밀한 범례/축을 작은 글씨로 해결하지 않는다.

DOCX 생성 스크립트는 기본 골격이다. 산출물의 의미와 페이지 배치를 검토한 뒤 필요한 부분을 작업 폴더에서 조정한다. 모든 페이지 렌더링을 직접 확인한 후 최종 파일을 제공한다. 원본 개인정보나 학생별 순위 목록은 기본 결과물에 넣지 않는다.
